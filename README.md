# 🧠 Brain Buzz

### Fun Mind Puzzles. Puzzles That Sting Your Mind.

Brain Buzz is a mobile-first, hand-drawn, casual brain teaser game with a **200-level adventure map**. Solve puzzles, earn coins, collect badges and rise from *Rookie Detective* to the top rank. Quick to start, hard to put down.

---

## ✨ Features

- 🗺️ **200 adventure puzzles** on a hand-drawn "Paper Map" with locked and unlocked levels
- 🏅 **Rank and Quest progress**, starting at Rookie Detective
- 🪙 **Coins**: earn them by solving puzzles and completing milestones
- 🎁 **Daily Puzzle and Daily Gift**: claim free coins every day (+50)
- 🎡 **Spin** for bonus rewards
- 🔥 **Day Streak** to reward playing every day
- 💡 **Clues / Hints** whenever you get stuck
- 🏆 **Badges and Milestones**: First Solve (+20), Brain Star (+50), Sharp Mind (+100) and more
- 📊 **Brain Records and Stats**: levels completed, coins and badges
- 🔊 Sound toggle and 📳 vibration (haptics) feedback
- 🔍 Pinch-and-drag zoom on mobile, zoom shortcuts on desktop
- 📱 Mobile-first design that also works on laptop and PC

---

## 🎮 How to Play

1. Tap **Play Now**, or open the **Levels Map** and pick your current level
2. Read the puzzle carefully and choose the correct answer
3. Stuck? Use a **Clue / Hint**
4. Solving levels earns coins, unlocks the next level and fills your Quest progress
5. Come back daily for the **Daily Puzzle**, **Daily Gift** and streak rewards
6. Complete milestones to unlock **Badges** and bonus coins

## ⌨️ Keyboard Shortcuts (Laptop / PC)

| Action | Key |
|--------|-----|
| Play / Next | `Enter` / `Space` |
| Clue / Hint | `H` |
| Restart Level | `R` |
| Levels Map | `M` |

| Zoom In / Out | `Ctrl` + `+` / `-` |

## 🚀 Getting Started

### Requirements

- [Node.js](https://nodejs.org/) v18 or above
- npm (comes with Node.js)

### Run Locally

```bash
# 1. Clone the repository
git clone https://github.com/saniakundu7/brain-buzz.git
cd brain-buzz

# 2. Install dependencies
npm install

# 3. Start the development server
npm run dev
```

Open the link shown in the terminal (usually `http://localhost:3000`) in your browser. For the best experience, open it on a phone or use your browser's mobile view.

### Build for Production

```bash
npm run build
```

The production files will be created in the `dist` folder. You can host them on Netlify, Vercel, GitHub Pages or any static hosting.
